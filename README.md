# Rimworld Races - Elves
![](About/Preview.png?raw=true) 
<p>Elves is the second module of the Rimworld Races series, heavily inspired in High Fantasy settings like Lord of the Rings and D&D.</p>
<p><h3>Personal Philosophy:</h3>This is my oldest mod. I began working in it around the Royalty DLC. Dark Elves are my favorite fantasy race, so I took the Big Great Otto's Drow mod as a template in which adding more content, especially lore. Later, the continued version of Kerevan helped me a lot to learn how to write XML properly and set a fully functional race (I still have nightmares about the pointy ears).</p><p>A second breakthrough came obviously with the Biotech DLC. For compatibility sake, I converted all my D&D races into xenotypes, elves also, although I treat them as separate races. Finally, I decided to add grey elves to the mod not so long ago, using the Lord of the Rims mod as a starting base.</p>
<p>Like every mod I made, the Elves module is designed to be complemented by others to recreate the sensation of a living world. A myriad of patches assure that every mod of mine lean to others. Also, the DLCs are integrated as much as possible. For example, if Royalty DLC is loaded, they'll be new weapon traits available, or if the Biotech DLC is present, the player will be able to brew a blood venom, an alchemist potion to end unwanted pregnancies, at the cost of a mild side effect though.</p>
<p><b>Recommended mod:</b> Aquiles Alchemy by Aquiles.</p>
