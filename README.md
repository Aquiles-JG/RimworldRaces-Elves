# Rimworld Races - Elves
![](About/Preview.png?raw=true) 
<p>Elves is the second module of the Rimworld Races series, heavily inspired in High Fantasy settings like Lord of the Rings and D&D.</p>
<p><h3>Personal Philosophy:</h3>This is my oldest mod. Dark Elves are my favorite fantasy race, so I took the Big Great Otto's Drow mod as a template in which adding more content, especially lore. Later, the adopted version of Kerevan helped me to learn how to write XML properly and set a fully functional race.</p><p>The Biotech DLC was another major breakthrough. I converted all my D&D races into xenotypes, elves also, although I treat them as separate races. Finally, I decided to add grey elves to the mod not so long ago, using the Lord of the Rims by Jecrell as a proving grounds.</p>
<p>Three factions for elves (one) and dark elves (two). Each one with their own apparel, weapons, furniture, floors, traders, etc., but with a common culture background. For example, elven shirts will be available for both races, but grey elves will refuse to wear the drow girdle. The Elves module is designed to be complemented by others to recreate the sensation of a living world. Also, the DLCs are integrated adding their own content. For example, if the Royalty DLC is loaded, they'll be new weapon traits available, or if the Biotech DLC is present, the player will be able to brew a blood venom, an alchemist potion to end unwanted pregnancies, and much more.</p>
<p><b>Recommended mod:</b> Aquiles Alchemy by Aquiles.</p>
